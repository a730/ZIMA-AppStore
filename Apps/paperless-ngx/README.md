# Paperless-ngx

Document management system that transforms physical documents into a searchable online archive.

- OCR with Tesseract (100+ languages)
- Machine-learning auto-tagging
- Full-text search
- PDF/A archival format
- REST API

## Quick Start

1. Install from CasaOS App Store
2. Set `PAPERLESS_SECRET_KEY` in CasaOS env settings (generate with `openssl rand -hex 32`)
3. Open http://localhost:8002
4. Create a superuser account
5. Drop documents into the consume folder to auto-import
