# BookStack

Free and open-source wiki designed for creating beautiful documentation.

- WYSIWYG and Markdown editors
- Books, chapters, and pages hierarchy
- Full-text search
- Role-based permissions
- LDAP/SAML/OAuth authentication

## Quick Start

1. Install from CasaOS App Store
2. Open http://localhost:6875
3. Login with admin@admin.com / password
4. Change password immediately
