# MCPHub

Unified hub server for managing multiple MCP (Model Context Protocol) servers.

- Centralized dashboard for monitoring all MCP servers
- Hot-swappable config — add/remove servers without restart
- Smart routing via vector semantic search
- SSE endpoint for connecting Claude Desktop, Cursor, etc.
- OAuth 2.0 support

## Quick Start

1. Install from CasaOS App Store
2. Open http://localhost:3010
3. Login with username `admin` (password auto-generated on first launch — check container logs)
4. Add your MCP servers via the dashboard
