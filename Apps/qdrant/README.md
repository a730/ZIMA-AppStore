# Qdrant

High-performance vector similarity search engine and vector database written in Rust.

- REST API (port 6333) and gRPC API (port 6334)
- HNSW indexing for fast approximate nearest neighbor search
- Payload filtering with vector similarity
- Built-in Web UI dashboard
- Scalar and product quantization

## Quick Start

1. Install from CasaOS App Store
2. Open http://localhost:6333/dashboard
3. (Optional) Set QDRANT_API_KEY in env settings to secure access
