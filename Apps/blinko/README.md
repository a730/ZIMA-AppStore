# Blinko

An open-source, self-hosted personal AI note tool prioritizing privacy.

## Features
- 🤖 **AI-Enhanced Note Retrieval**: Quickly search and access notes using natural language queries.
- 🔒 **Data Ownership**: All notes and data are stored securely in your self-hosted environment.
- 🚀 **Efficient and Fast**: Effortlessly capture ideas and store them as plain text.
- 💡 **Lightweight Architecture**: Fast performance with Markdown support.

## Installation
Install via ZimaOS App Store. 

## Configuration
After installation, you can customize the `NEXTAUTH_SECRET` and `NEXT_PUBLIC_BASE_URL` environment variables in the app settings.
