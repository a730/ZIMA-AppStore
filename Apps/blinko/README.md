# Blinko

Privacy-first, open-source personal AI note tool for quickly capturing and organizing thoughts.

## Features
- AI-enhanced note retrieval with natural language search
- Data ownership — all notes stored on your server
- Lightweight Markdown-based notes
- PostgreSQL-backed persistence
