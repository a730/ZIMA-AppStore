# HandBrake

Open-source video transcoder for converting video from nearly any format to modern, widely supported codecs.

- Web GUI accessible from any browser
- Supports all major codecs (H.264, H.265, VP9, AV1, etc.)
- Batch processing with watch folders
- Preset-based encoding profiles

## Quick Start

1. Install from CasaOS App Store
2. Open http://localhost:3007
3. Place source videos in the `/storage` mount
4. Start transcoding via the web interface
