# MusicBrainz Picard

Cross-platform music tagger that automatically identifies and tags music files using the MusicBrainz database.

- Full GUI accessible from any web browser (noVNC)
- Automatic audio fingerprinting and metadata lookup
- Batch tagging for entire music libraries
- Album art download
- Scriptable tagging with plugins

## Quick Start

1. Install from CasaOS App Store
2. Open http://localhost:5800
3. Browse to /storage and add your music files
4. Select files and click "Cluster" to group by album, then "Lookup" to tag
