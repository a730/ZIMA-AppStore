# Mission Control

Open-source dashboard for AI agent orchestration.

- 32 panels: tasks, agents, skills, logs, tokens, memory, security, cron, alerts, webhooks, pipelines
- Real-time everything: WebSocket + SSE push updates
- Zero external dependencies: SQLite database, single container
- Role-based access: viewer, operator, admin
- Multi-gateway: connect multiple agent gateways simultaneously

## Quick Start

1. Install from CasaOS App Store
2. Open http://localhost:3000/setup
3. Create your admin account
4. Connect agent gateways or use CLI agents directly
