# Paperclip

Open-source orchestration for zero-human companies. Define goals, hire agents, and run your business autonomously.

- Org charts, budgets, governance, and goal alignment
- Works with OpenClaw, Claude Code, Codex, Cursor, Bash, HTTP
- Embedded PostgreSQL — no external database required
- Agent heartbeat protocol, task management, cost tracking

## Quick Start

1. Set `BETTER_AUTH_SECRET` in CasaOS env settings (generate with `openssl rand -hex 32`)
2. Open http://localhost:3100
3. Complete the setup wizard
4. Create your first company and hire agents
