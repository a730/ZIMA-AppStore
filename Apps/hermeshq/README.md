# HermesHQ

Control plane for Hermes Agent instances.

## Features
- Docker-first control plane
- Web UI and RBAC
- Task dispatch and schedules
- Inter-agent communication
- Enterprise MCP access

## Installation
Install via ZimaOS App Store. 

**Note:** HermesHQ must be built from source. The first deployment will take several minutes.

## Initial Login
- **Username:** admin
- **Password:** admin123

It is highly recommended to change the `JWT_SECRET` and `ADMIN_PASSWORD` via environment variables after the first installation.
